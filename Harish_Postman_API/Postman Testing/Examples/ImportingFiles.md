Importing Files
In this example, we will look at some of the methods for importing various files into Postman.

Importing a Collection File
Sharing collections with different people is an easy way to get them up to speed quickly. Here's how to import a collection file:

Press the Import button:

Located at the top left of the application.

Import the File:

In the Import File tab, either drop the collection file into the grey shaded area or navigate to the file on your machine using the Choose Files button.

A message will confirm the successful import.

Importing Environment Files
The process for importing environment files is similar to importing collection files:

Press the cog icon:

Located at the top right of the application, just above the Save button.

Press the Import button.

Choose the File:

Select the file from your machine and click Open.

You will receive a notification confirming the successful import.
